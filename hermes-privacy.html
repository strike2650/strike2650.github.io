Privacy policy

Last updated: 2 November 2026

Who uses it. Hermes assistant is used only by its owner, with the owner's own Google account.

Google user data accessed. Google Calendar, Drive, Docs and Sheets; Contacts (read-only); and YouTube (read-only: subscriptions, playlists and likes).

How it is used. Solely to answer the owner's own requests. No data is sold, shared with third parties, used for advertising, or used to train AI or machine-learning models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security. The OAuth token is stored only on the owner's computer in a file readable solely by the owner's user account.

Retention and deletion. Access can be revoked at any time at myaccount.google.com/permissions; data remains in the owner's Google account under the owner's control.

Contact. Open an issue on this site's GitHub repository.
