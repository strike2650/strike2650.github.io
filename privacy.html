Privacy policy

Last updated: 2 November 2026

Who uses it. rclone backup is used only by its owner, with the owner's own Google account.

Google user data accessed. The app requests Google Drive access so it can upload, list, update and remove backup files in the owner's own Drive (the Backups folder).

How it is used. Drive access is used solely to store and maintain the owner's backups. No data is sold, shared with third parties, used for advertising, or used to train AI or machine-learning models. Use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Storage and security. The OAuth token is stored only on the owner's computer in a file readable solely by the owner's user account. Backup archives are encrypted before upload.

Retention and deletion. Access can be revoked at any time at myaccount.google.com/permissions; files remain in the owner's Drive under the owner's control.

Contact. Open an issue on this site's GitHub repository.
